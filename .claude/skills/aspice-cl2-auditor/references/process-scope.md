---

**Note:** the VDA "scope" (the typical supplier assessment scope for automotive OEM programs) is usually a subset of this, most commonly:
ACQ.4, SPL.2, SYS.1–5, SWE.1–6, SUP.1, SUP.8, SUP.9, SUP.10, MAN.3.
MLE.x/SUP.11 apply only when the project includes a machine-learning component; HWE.x only when hardware development is in scope. Confirm the actual assessment/audit scope with the user before assuming full coverage.
